# Команды платформы 1С

Поиск в пакетах toolkit не запускает платформу. Сборка внешней обработки,
изменение информационной базы и администрирование являются отдельными задачами,
для которых нужны установленные инструменты 1С и соответствующий доступ.

## Выбор инструмента

| Инструмент | Область применения |
| --- | --- |
| `1cv8`, режим Designer | операции конфигуратора, включая внешние обработки и отчёты |
| `CREATEINFOBASE` | создание информационной базы через запуск платформы |
| `ibcmd`, `ibsrv` | операции, поддерживаемые этими средствами в установленной версии |
| `ragent`, `ras`, `rac` | службы и администрирование кластера |

Перед запуском сверяйте синтаксис с документацией установленной версии.
Наличие исполняемого файла не подтверждает поддержку конкретного параметра.
Не переносите ключи команд, схему подключения или правила проверки результата
между этими инструментами без проверки.

## Помощники в toolkit

[Инструкция и параметры](../tools/1c/README.md) описывают два shell-скрипта:

- `build_external_data_processor.sh` собирает внешнюю обработку или отчёт из XML.
- `unpack_external_data_processor.sh` выгружает внешний файл в XML.

Они вызывают отдельно установленный `1cv8`. Платформа и лицензия не входят в
skill. Эти операции не нужны для извлечения HBK и поиска по SQLite.
Пути к скриптам отсчитываются от корня toolkit или экспортируемого пакета.

## Проверка результата

Перед операцией определите точную базу, версию платформы, входные и выходные
пути. Для изменения базы используйте согласованный пользователем сценарий.
Проверяйте код завершения, доступный результат команды, журнал и созданный
артефакт. Не считайте наличие файла журнала доказательством успешной сборки.

Временная база полезна для изолированной сборки, но её создание и очистка
зависят от конкретного помощника. Читайте его параметры; не предполагайте,
что все временные каталоги и журналы удаляются автоматически.
Не включайте пароли в общие примеры и опубликованные журналы.

После получения обработки проверяйте её в целевой версии платформы.
Для изменений BSL используйте диагностику и тесты проекта. Успешный поиск в
справке и успешная упаковка файла не доказывают правильность его поведения.
